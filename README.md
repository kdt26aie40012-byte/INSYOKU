# INSYOKU
# （花園）メニュー・オーダーシステム

## 概要

店名は『花園』で、お客さんの端末から注文を受けるためのシステムを作る。
お店の方向性は**すし**で、にぎり・軍艦・巻物・サイドメニュー（茶碗蒸し・かけうどん・味噌汁）を実際の写真付きで表示する。

## 起動方法

```
git clone https://github.com/kdt26aie40012-byte/INSYOKU.git
cd INSYOKU
```

`index.html` をブラウザ（Chrome / Edge など）で開くと起動します。インストールは不要です。

テストは `test.html` をブラウザで開くと結果が表示されます（Node.js がある場合は `node test_calc.js` でも実行できます）。

## システム構成

システム起動時に店名を1.5秒表示して、その次にメニューを表示する。
年齢や性別の入力でおすすめを表示できると表示して、入力されたらおすすめの項目を追加する。年齢や性別には『NO』と回答したくない場合の選択肢も用意する。
年齢の入力時には数字と『NO』のみを入力できるようにし、性別は選択形式にして選択肢は『男性』『女性』『NO』にする。
メニューの画像をクリックしたらそのメニューの数量の指定へと移行する。
注文内容をデータとして記録する。
会計については、会計ボタンをクリックした際に注文内容のデータから注文しているメニューの内容と個数を取得して合計金額を算出して、注文内容の一覧と豪献金額をポップアップ表示する。そのポップアップの下には左に『会計に進む』を、右に『食事に戻る』のボタンを表示する。
『会計に進む』を選択されたら『ご来店ありがとうございました』と5秒間表示して注文内容のデータを初期化して初期状態で待機する。
『食事に戻る』を選択されたらポップアップを閉じて元の画面に戻る。

## 画面と機能

### 画面構成

メニュ－の画像を並べて表示して、右端には『注文履歴』『会計』を設置する。
メニューはおすすめの項目と全体の項目とアレルゲンなしの項目を作る。
アレルゲンが含まれるメニューは、写真の左上に赤文字で含まれるアレルゲンを明記する。
アレルゲンなしの項目を選択したら、チェックシート形式で『エビ』『カニ』『タマゴ』『小麦』『乳製品』『そば』『イカ』『イクラ』『サケ』『サバ』『貝類』『大豆』『山芋』『ゴマ』の項目を表示し、選択されたアレルギーが含まれるメニューを除外して表示する。

## 自分で決めたこと

<!-- 要件に書かれていなかったことと、そう決めた理由を書く。 -->

| 決めたこと | 理由 |
|---|---|
|『NO』の回答の追加|答えたくない人への配慮|
|食事に戻る選択肢の追加|間違えて選択してしまった場合や合計金額を確認したいだけの人に必要|
|年齢は0〜120の範囲に限定|ありえない数字でおすすめが出ないようにするため|
|数量は1〜99個に限定|0個や極端な数の注文を防ぐため|
|注文がないときは『会計に進む』を押せない|0円の会計で初期化されてしまうのを防ぐため|
|同じメニューを再度注文したら個数を足す|注文履歴と会計を見やすくするため|
|お店の方向性をすしにした|メニューに統一感を出すため|
|価格は1皿（2貫）単位、税込表示|回転ずしのように皿単位で注文しやすくするため|
|メニュー写真は Wikimedia Commons の自由ライセンス写真を使用|実際の写真を使いつつ、著作権の条件を守れるようにするため（クレジットを images/CREDITS.md と画面下に表示）|
|アレルギーを何も選択していないときは全メニューを表示|何も選ばれていない段階で除外するものがないため|
|しょうゆのアレルゲンはメニューに含めない|しょうゆは本人に注意してもらうため。大豆を選択したときだけしょうゆへの注意書きを表示する|
|かけうどんを追加|小麦を含むメニューとして用意するため|
